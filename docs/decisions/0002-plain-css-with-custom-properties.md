# 0002 スタイリングはプレーン CSS + カスタムプロパティ（Tailwind / Sass なし）

関連 Issue: #31 / #48

## 背景

デザインの正本（[docs/design/README.md](../design/README.md)）は色・タイポグラフィ・スペーシングをトークンとして定義している。画面数は 8、コンポーネントは 30 程度で、スタイルの大半はトークンの参照とレシピ（glow 付き数字・mono タブラー数字など）の使い回しである。

## 決定

- Vue の scoped CSS を使い、値は `src/styles/tokens.css` の `:root` カスタムプロパティに集約する（単一ソース）
- 多プロパティのレシピは共通 CSS ではなくプリミティブコンポーネントに内包して使い回す
- Tailwind も Sass も使わない

## 検討した代替案

- **Tailwind**: ユーティリティクラスはトークンを class 名で再定義することになり、デザイン正本との対応が二重になる。テンプレートが長くなり、scoped CSS の「ルート要素名 = コンポーネント名」という読み方も崩れる
- **Sass**: 変数・mixin が欲しくなる場面はカスタムプロパティとプリミティブへの内包で足りる。ネストは CSS ネイティブのネスト構文で書ける。ビルドの依存を増やす理由が無い
- **CSS Modules / CSS-in-JS**: scoped CSS が Vue の標準機能として同じ隔離を提供する

## 帰結

- 必要になった時点で Sass を後付けできる（プレーン CSS は Sass の部分集合）
- カスタムプロパティは継承で scoped CSS の境界を越える。この性質を利用した越境ルールは [0007](0007-scoped-css-boundary-token-redefinition.md) で定める
